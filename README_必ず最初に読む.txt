食事管理 AI相談・週間月間献立版 v1.4.4

【v1.4.4 今回の追加】
1. ごはんのおかわり入力を追加
・食事画像を解析する前に「2杯目」「3杯目」「4杯目」を選択できます。
・各杯ごとに「なし／小盛り（約100g）／中盛り（約150g）／大盛り（約200g）」を選べます。
・3杯目は2杯目を選んだ時だけ、4杯目は3杯目を選んだ時だけ表示します。

2. おかわり分を栄養計算へ反映
・画像に写っている最初のごはんは従来どおりAIが判定します。
・画像に写っていない追加分だけ、おかわり欄で選択してください。
・おかわり分はカロリー、たんぱく質、脂質、炭水化物（PFC）へ加算します。
・解析結果画面に「おかわりを栄養計算に追加済み」と表示します。
・食事名と履歴にも「ごはんおかわり（2杯目 中盛り…）」が残ります。

3. 重複判定も修正
・同じ食事画像でも、おかわり内容が異なる場合は別内容として扱います。

【おかわり量の計算目安】
炊いた白ごはんを目安として計算します。
・小盛り：約100g
・中盛り：約150g
・大盛り：約200g
量は目安なので、実際の茶碗サイズや盛り方で差が出ます。

【重要：GASの更新が必要】
今回のおかわり分を栄養計算へ反映するため、Code.gs の上書きと再デプロイが必要です。

【1．GASを更新】
1. 対象スプレッドシートから「拡張機能」→「Apps Script」を開く
2. 既存の Code.gs の内容をすべて選択
3. このZIP内の Code.gs の内容へ上書きして保存
4. 「デプロイ」→「デプロイを管理」
5. 既存デプロイの鉛筆マークを押す
6. バージョンを「新バージョン」にして「デプロイ」
7. GAS WebアプリURLは通常そのまま利用できます

【2．テスト版を確認】
1. GitHubの meal-management リポジトリを開く
2. 「＋」→「Upload files」
3. mobile-v144.html を追加して Commit changes
4. スマホで次を開く
   https://webrich60.github.io/meal-management/mobile-v144.html
5. 「2杯目」で小・中・大のどれかを選び、食事画像を1件解析
6. 結果画面で、おかわり表示とカロリー・炭水化物への加算を確認

【3．正常なら本番へ反映】
1. 同じGitHubリポジトリで「＋」→「Upload files」
2. このZIP内の index.html をアップロード
3. 既存の index.html を新しい内容へ更新して Commit changes
4. 通常URLを開く
   https://webrich60.github.io/meal-management/

・食事画像のAI解析
・PFCグラフ
・塩分警告
・中性脂肪評価

【スプレッドシート】
列の追加は不要です。v1.4.3までの列構成をそのまま使います。
おかわり内容は食事名へ追記され、栄養値は既存のカロリー・PFC列へ合算されます。

【注意】
食事画像・入力内容から推定した健康管理上の参考情報です。
血液検査値の測定、診断、治療、薬の変更を行う機能ではありません。
