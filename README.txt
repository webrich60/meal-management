■ 更新手順（すでにGAS v1.8.1が正常動作している場合）
1. 今のGitHubの index.html をバックアップする。
2. このZIP内の index.html でGitHubの index.html を上書きする。
3. Commit changes を押して更新を反映する。
4. スマホでGitHub Pagesの公開URLを開き、再読込する。
5. 上のヘッダーに v1.9.0 と表示されることを確認する。
6. 「定番メニュー」「体重管理」「分析」などのメニューを開いて確かめる。

この場合、GASの上書きや再デプロイは不要です。既存のスプレッドシートもそのままです。

■ GASが旧バージョンの場合
定番メニューの保存などが動かず「GASが古い」と表示される場合、まず接続しているURLを確認してください。
本当のGASが旧版なら、既存のGASコードをバックアップしてから付属 Code.gs に変更し、
「デプロイを管理」→既存のデプロイを編集→「新バージョン」で再デプロイしてください。

■ 注意
・画面プレビューに載せた体重・栄養数値はテスト用の架空データです。
　アプリ本体は接続先のGASから実データを読んで表示します。
・実記録が取得できない場合は「—」や取得エラーを表示し、数値を捏造しません。
・朝昼の摂取表示は朝昼のみの合計で、1日の総摂取カロリーではありません。
・写真解析は引き続きGemini API/GASを使用します。AIモデル・APIキー・既存の履歴は変更しません。
・新規UIは HTML/CSS/JS のローカル模擬APIで機能試験済みですが、実際のGAS/スマホとの本番接続試験は未実施です。
・既存データを保護するため、スプレッドシート自体の変更は行っていません。
