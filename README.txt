健康食事アドバイザー v1.7.2 － AIモデル設定更新版
更新日：2026-10-30

【修正点】
1. Code.gs の Gemini API 呼び出し2か所を、公式APIモデルID
   gemini-3.1-flash-lite に変更しました。
   ・画像／テキストからの食事分析（analyzeMealWithGemini_）
   ・詳細アドバイス、献立、体重増加の原因分析など（callGeminiJson_）
2. GASに「updateAiModelPropertiesOnce」関数を追加しました。
   一度実行すると、既存のスクリプトプロパティのうち「MODEL」「モデル」を
   キー名に含み、かつ旧モデル名を値にもつ項目だけ、新しい正式IDに更新します。
   Gemini: gemini-3.1-flash-lite
   ChatGPT Luna: gpt-6-luna
   GEMINI_API_KEY、OPENAI_API_KEYなどAPIキーや食事データには触れません。
3. APIバージョンと画面表示を v1.7.2 に更新しました。

【重要な注意】
・この食事管理ツールの現行GASはGemini APIを使用しています。
  OpenAI APIの呼び出し処理はもともと存在しません。
  OpenAIモデルのプロパティが既存の場合には名称を修正しますが、
  これだけでChatGPTによる分析が追加されるわけではありません。
・こちらから実際のGASのスクリプトプロパティを直接閲覧・更新することは
  できません。下記の手順に従って一度実行してください。
・スクリプトプロパティのキー名がMODEL/モデル以外、あるいは未知のモデル値の
  場合は自動変更しません。GAS → プロジェクトの設定 → スクリプト
  プロパティで確認し、必要な場合だけ手動更新してください。

【更新手順】
1. 現在の Apps Script の Code.gs を念のためバックアップする。
2. ZIP内の Code.gs の全文で既存の Code.gs を上書きし、保存する。
3. Apps Script エディタ上部の関数選択から
   updateAiModelPropertiesOnce を選んで「実行」を一度押す。
   ※初回実行時に追加の承認が求められる場合があります。
4. 実行ログに「AIモデル設定を更新しました」と出たら対象プロパティを確認。
   「変更対象の旧モデル設定は見つかりませんでした」は異常ではありません。
5. 「デプロイ」→「デプロイを管理」→既存のWebアプリの鉛筆→
   「新バージョン」を選択してデプロイする。
6. GitHubの index.html を同梱最新版に入れ替えてコミットする。
   mobile-v172.html は必要な場合の動作確認用です。

【検証範囲】
・モデル名は Google / OpenAI の公式モデルカタログで確認済み。
・GASのJavaScript構文と置換箇所を静的に検証済み。
・Apps Script実環境のモデル呼び出しやスクリプトプロパティ変更、
  GitHubの更新はまだ実行していません。
・GASのAPIキー、スプレッドシート、既存食事データの書き換えはありません。
