食事管理 × RE:SELF 融合版 v1.8.0
====================================
2026-11-24

同梱ファイル
・index.html       ：GitHub Pagesへアップロードする本番用
・mobile-v180.html ：スマホの画面を確認するための同内容ファイル
・Code.gs          ：既存のGoogle Apps Scriptへ上書きする最新版
・README.txt       ：この説明

■ この版で追加した機能
(1) 朝昼・体重の集中管理モード（開閉可能）
(2) 選択日を基準に7日・14日・30日の朝体重グラフと平均・目標との差を表示
(3) 朝食・昼食の登録日数と、実際に登録された日の平均摂取カロリーを表示
(4) 朝食・昼食の定番メニューの登録・編集・削除（見本写真は任意）
(5) 定番メニューを従来の「食事テキスト入力」に挿入してAI解析・保存できる
(6) 1日ごとの朝体重・体調メモのGAS保存とPC・スマホ同期
(7) 7日・14日・30日の朝昼の記録と体重を使うAI集中分析
(8) 既存の朝食未登録確認、写真解析、間食警告、PFC分析、長期分析を維持

■ 保存先
同じGoogleスプレッドシートに、初回使用時に次のタブを自動作成します。
・朝昼体重メモ
・朝昼定番メニュー
・朝昼目標設定
元の食事記録タブを削除したり置き換えたりしません。
定番メニューの見本写真を選んだ場合は、圧縮した画像だけが「朝昼定番メニュー」の列に保存されます。
通常の食事写真は従来通り保存せず、AI解析のためだけに送信します。

■ 更新手順（大切）
1. 現在のGASのCode.gs全文をテキストファイルへコピーしてバックアップ。
2. 同梱Code.gsで、既存のGAS Code.gsを全文上書きして保存。
3. GASの「デプロイ」→「デプロイを管理」→対象デプロイの鉛筆→「新バージョン」を選んでデプロイ。
4. GitHub Pagesの既存index.htmlを、同梱index.htmlで置き換えてコミット。
5. サイトのバージョン表記がv1.8.0になっていることを確認。
6. 「朝昼・体重 集中管理」を開き、体重・目標・定番メニューの保存をそれぞれ確認。
既存のGAS URLは、同じWebアプリの既存デプロイを更新する場合は通常そのままです。

■ 使い方（短期管理）
1. 毎朝、なるべく同じ条件で測った体重を画面上部の「体重 kg」に入力。
2. 「朝体重とメモをスプレッドシートに保存」で保存。
3. 朝食・昼食を写真または文章で従来通り登録。
4. よく食べる食事は「よく食べるメニューを登録・編集」で登録し、選択後に食事欄へ挿入。
   ※選択しただけでは食事登録にはなりません。AI解析・記録のボタンで保存してください。
5. 7日・14日・30日のグラフと登録率を確認し、「朝・昼・体重をAIで分析する」を実行。
6. 一時的な管理を終えたら集中管理の「閉じる」で画面を縮められます。データは保持されます。

■ 注意
・朝食や昼食の未登録日は0kcalとして計算しません。未登録と食事なしは別扱い。
・朝昼だけの記録では、1日の総摂取量や体重増加の原因は断定できません。
・見本メニューの「kcal目安」は記録用。食事分析は実際に入力・撮影した内容の推定値を使います。
・長期の体重分析も、追加した朝体重専用タブを読めるように調整しました。
・朝体重の保存と食事の保存は別操作です。重複食事登録を避けてください。
・過去のRE:SELFアプリ固有のデータは、このプログラムZIPだけでは復元／移行できません。
・APIキーは既存のGEMINI_API_KEYを使用。古いキーを削除する必要はありません。
・OpenAI APIは使っていません。GASのgpt-6-luna設定変更は維持されていますが、OpenAI分析機能は未実装です。
・既存の長期体重分析・AI食事解析は残しています。
